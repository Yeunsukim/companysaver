# 사내 스크린세이버
- Company Screen Saver v1.0.0
- `server/` : 콘텐츠 등록·관리 서버 (Node.js 22.13+ / Express / SQLite 내장 `node:sqlite`)
- `client/` : 각 PC에 설치되는 스크린세이버 (Electron, `.scr`)
- `samples/` : 샘플 (JS/CSS 포함 HTML ZIP, SVG 이미지)

## 배포 파일 (개발 PC에서 빌드 → 각 PC에 전달)
| 대상 | 파일 | 빌드 |
|---|---|---|
| 서버 PC 1대 | `server/release/CompanySaverServer-Setup.exe` | `server\installer\build.ps1` |
| 사용자 PC 전체 | `client/release/CompanySaver-Setup.exe` | `cd client; npm run dist` |

빌드는 개발 PC에서만 필요합니다. 배포 대상 PC에는 Node.js가 필요 없습니다.

## 서버 설치 (CompanySaverServer-Setup.exe)
- 설치 중 **웹 포트**(기본 8080)와 **관리자 비밀번호**를 입력합니다. 포트가 이미 사용 중이면 알려 줍니다.
- 방화벽에서 해당 TCP 포트를 허용하고, PC 부팅 시 자동 실행(SYSTEM 계정, 종료되면 5초 뒤 재시작)으로 등록합니다.
- 데이터(DB, 업로드 파일)는 `C:\ProgramData\CompanySaverServer`에 저장되며 업데이트·제거해도 남습니다. 로그: `server.log`.
- 관리 화면: `http://서버IP:포트/admin/` (설치 후 바탕화면 바로가기 생성)
- **트레이 아이콘**(알림 영역, 로그인할 때마다 자동 실행): 초록=서버 실행 중 / 빨강=중지. 우클릭 메뉴에서 관리 화면 열기, 클라이언트 접속 주소 복사(클라이언트 설치 시 입력할 `http://IP:포트`), 서버 시작·재시작·중지(관리자 권한 확인 창이 뜸), 로그 보기. 트레이를 종료해도 서버는 계속 실행됩니다.
  - 트레이는 컴파일된 exe가 아니라 PowerShell 스크립트(`tray.ps1`)입니다. (직접 컴파일한 서명 없는 exe는 백신이 삭제하는 것을 확인함.) PowerShell 스크립트 실행이 정책으로 막힌 PC에서는 트레이만 동작하지 않으며 서버 자체는 정상 동작합니다.
- 직접 실행(개발용): `cd server; npm install; npm start` — 초기 계정 `admin` / `admin1234`(환경변수 `ADMIN_USER`, `ADMIN_PASS`, `PORT`, `DATA_DIR`)

## 클라이언트 설치 (CompanySaver-Setup.exe)  
- 설치 중 **서버 주소**(예: `http://192.168.0.10:8080`)를 직접 입력합니다. 자동 검색은 없습니다(다른 기관 서버가 검색·접속되는 것을 방지).
- 현재 사용자의 화면 보호기로 자동 등록됩니다(대기 10분). 제거는 "앱 및 기능"에서.
- 서버 주소는 화면 보호기 설정의 "설정" 버튼(`/c`)에서 바꿀 수 있고 "연결 테스트"를 지원합니다.
- 개발/테스트: `cd client; npm install; node node_modules\electron\install.js; npm run start:debug` (창 모드), `npm start` (전체화면)

## 관리 화면
- **콘텐츠 관리**: 상태별 요약 카드, 검색/부서 필터, 드래그로 재생 순서 변경, 사용 스위치, 수정·삭제
- **콘텐츠 등록**: 종류 선택(HTML ZIP/단일 HTML, 이미지·동영상 파일, 이미지·동영상·웹페이지 URL), 게시 기간(빠른 선택), 요청 부서/담당자(기록용), 표시 시간, 표시 모니터, 저장 전 실시간 미리보기
- **미리보기**: 듀얼 모니터 시뮬레이션(모니터별 재생 목록·진행 바·일시정지/다음)

## 화면 맞춤 (모니터 크기가 달라도 자동으로 맞춤)
- 이미지·동영상: `전체 보이기(여백)` = 비율 유지, 남는 곳은 검은색 / `꽉 채우기` = 빈틈없이 채움(가장자리 잘림)
- HTML·웹페이지:
  - `자동(반응형)`: 모니터 크기를 그대로 사용 → vw/vh, %, flex, 창 크기에 맞춰 그리는 canvas 등으로 제작
  - `기준 해상도로 확대·축소`: 1920×1080 같은 고정 크기로 제작한 HTML을 그 크기로 그린 뒤 모니터에 맞춰 확대/축소 (여백/꽉 채우기 선택 가능). 제작자가 모니터 크기를 신경 쓰지 않아도 됩니다.
- 관리 화면 미리보기에서 화면 비율(16:9, 16:10, 21:9, 4:3)을 바꿔 가며 확인할 수 있습니다. 샘플: `samples/fixed-1920x1080.html`

## 동작 규칙
- 게시 기간 안이고 사용 중인 콘텐츠만 재생합니다. **요청 부서/담당자는 기록용**이며 재생 여부와 무관합니다(모든 PC에 동일하게 표시).
- 모니터별 재생: `모든 모니터` / `주 모니터만` / `보조 모니터만`. 각 모니터가 자기 목록을 독립적으로 순환.
- 클라이언트는 실행 시와 N분마다 서버와 동기화하고 `%LOCALAPPDATA%\CompanySaver\cache`에 저장 → 서버 불통 시 캐시로 재생.
- HTML 콘텐츠는 입력을 가로채지 않도록 투명 덮개 아래에서 실행되므로 콘텐츠 내 클릭 상호작용은 불가(스크린세이버 특성).

## 보안 참고
- 통신은 HTTP(암호화 없음)이고 `/api/playlist`, `/content/*`는 로그인 없이 읽을 수 있습니다. 사내망 전용으로 사용하세요.
- 관리자 API만 로그인(세션)이 필요합니다. 초기 비밀번호는 설치 시 지정하세요.
- 서명 없는 설치 파일·스크립트는 백신이 차단할 수 있습니다. 배포 전에 사내 백신이 설치되어 있는 PC에서 설치를 시험하고, 필요하면 백신 예외 등록 또는 코드 서명을 하세요.
